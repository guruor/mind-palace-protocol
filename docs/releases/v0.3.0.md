# Mind Palace Protocol v0.3.0

## Outcome

This release adds the vendor-neutral contracts needed to describe document
types, Knowledge Method packages, Storage Binding packages, and instance
selection. It does not install external packages or change common memory.

## Changes

- Add a shared declarative extension-package schema.
- Add a complete document-type contract schema.
- Add Knowledge Method and Storage Binding package schemas.
- Add an instance-configuration schema for method and binding selection.
- Add valid and invalid fixtures for every new contract.
- Add a simple extension-authoring guide.
- Define resource classes and cache policy as package metadata.

## Compatibility

The new contracts are additive. The current `product-engineering` method and
bindings have not yet been converted to package manifests. Existing client and
common-memory installation behavior remains unchanged. Common memory remains on
active `v0.1.0`.

## Rollback

No external state is written by this release. Rollback means continuing to use
the existing `v0.1.0` common-memory release and ignoring the additive package
schemas until a later release uses them.
