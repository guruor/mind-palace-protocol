# Mind Palace Protocol v0.9.2

## Outcome

This release closes the final model-mediated transport gap in compact
common-memory staging. The deterministic payload is uploaded as a Markdown file
and verified by digest after download.

## Changes

- Transfer the generated payload through the provider's binary upload path.
- Store one Markdown attachment on one compact release record.
- Count attachment bytes separately from page text.
- Require exact downloaded SHA-256 verification before activation.
- Extend provider and write-plan budgets for one bounded payload attachment.
- Allow installation state to describe an attachment-backed payload.

## Compatibility

Document and migration semantics remain compatible with `v0.9.1`. The release
changes only common-memory projection transport and verification. Existing
release records remain inert unless explicitly activated.

## Rollback

Mark only the candidate release blocked and leave the active pointer unchanged.
Do not remove the prior active release until the new release and client
resolution are verified.
