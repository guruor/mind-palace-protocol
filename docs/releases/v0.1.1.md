# Mind Palace Protocol v0.1.1

## Compatibility

This is a compatible hosted-client installation and validation clarification.
Artifact schemas and the `product-engineering` methodology remain at `0.1.0`.
Existing `0.1.0` installations remain active until an explicit staged upgrade;
clients must not switch merely because this release is newer.

## Changes

- Add one canonical hosted-chat custom-instructions adapter.
- Make ChatGPT and hosted Claude use native persistent instructions by default;
  Skills and plugins are no longer setup requirements.
- Make `INSTALL.md` sufficient as the only link supplied to a capable client.
- Require hosted clients to print exact manual host actions and wait for user
  confirmation before claiming persistent setup.
- Replace the ambiguous full-workflow term "live canary" with separately
  reported Fresh-Client Setup, Cross-Client Handoff, and Approved Write Canary
  stages.
- Add validation that prevents host-specific adapters from copying the canonical
  custom-instructions block.

## Upgrade And Rollback

Stage and validate `v0.1.1`, replace only the delimited hosted-chat adapter
block, and run the Fresh-Client Setup Check in a new conversation. Preserve the
`v0.1.0` release and prior adapter block for rollback. This release does not
grant connector access, production write authority, or migration approval.
